## 数据集摘要
本排污口检测数据集共10433张图像，分辨率640×640，仅包含**排污口**单一类目标，标注总量11718个。数据集划分训练、验证、测试子集，同时配套YOLO、VOC、COCO三种主流格式标注，适合水域无人机航拍排污口自动识别、水环境监管目标检测模型训练。

## 应用场景
- 河湖、水库、近海无人机航拍排污口排查
- 水环境执法、生态环境监测巡检
- 河道排污口智能化识别、溯源预警算法研发

## 应用价值
1. 单类别专注排污口目标，适合环境监测部门轻量化检测模型训练；
2. 数据划分规范，可直接用于模型训练、精度评估；
3. 三种标注格式，适配YOLO、MMDetection等绝大多数目标检测框架；
4. 覆盖不同光照、水域背景下排污口样本，适配野外水域巡检复杂场景。
